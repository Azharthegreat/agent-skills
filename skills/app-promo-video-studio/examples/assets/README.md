# Example assets

The screenshots used by `video_spec.example.json` are not included, because they show directory
records. Capture your own app's screens and save them here with the same names before running the
example:

- `home_top.png`: the top of the app's home screen
- `card1.png` to `card5.png`: one result card per proof scene

`icon.png` is the app icon used on the end card and thumbnail.
