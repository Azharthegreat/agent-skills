# Example project profile: MetaCyberGuru courses

A worked example of the defaults one owner settled on for a course series. Treat it as a pattern
for writing your own profile, never as universal instructions. Resolve paths from the current
repository checkout, not from a machine-specific drive.

- Course root: a dedicated folder per course inside the project repository.
- Presenter: the owner's own authorized portrait, saved in Grok as the character `@Azhar`. Never
  substitute another person's likeness.
- Logo: the exact supplied logo file, top-left. Inspect the file and the reference registry before
  use.
- Set: a professional studio reference (`@CourseStudio`), not the background of the portrait.
  Select the actual saved references; names alone do not prove a reference is attached.
- Voice: the owner-approved pilot sample. Locate the actual sample and its review evidence before
  continuing; never invent a voice ID.
- Format: reference-based 720p, 16:9, 15-second generations with native audio, mixing presenter,
  teaching board, diagram and code views in the edit. Re-verify the current options each run.
- Channel: `https://www.youtube.com/@MetaCyberGuru`. Verify the active account and destination
  before any upload. Never bundle login or session state in this skill.
- Review gate: upload a finished part as **Unlisted** for review first, and stop. Start the next
  part only after the owner approves the uploaded one.
